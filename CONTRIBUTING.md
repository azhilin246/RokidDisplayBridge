# Contributing

Bug reports, reproducible diagnostics, documentation fixes, and feature discussions are welcome.

Before opening a report:

1. Verify the problem on the latest release.
2. Remove device serials, credentials, signing material, private media, and captured screen content.
3. Include the mode, Android versions, exact app version, reproduction steps, and sanitized logs.

Code contributions require a separate written contributor agreement that lets Alexander Zhilin commercially use and relicense the contribution. Please discuss the change in an issue before opening a code pull request. Unsolicited code pull requests may be closed until that agreement is in place.

Forks remain allowed for the noncommercial purposes granted by the repository license. This project does not grant third parties commercial-use rights.
